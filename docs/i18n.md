# Bilingual copy (EN / ES)

Visible text is English and neutral Spanish. Spanish uses tú (`puedes`, `elige`, `toca`). It does not use voseo (`vos`, `podés`, `elegí`). Both languages say the same thing. A missing key must not appear on screen as the raw key.

The language lives in `localStorage["bitcoinizate-lang"]` (`en` or `es`). The hub reads the same key. `BZ.setLang` writes it, runs `BZ.apply`, then fires `bz-lang`.

## Where text lives

| Kind | Where | How it is chosen |
| --- | --- | --- |
| Shared UI (menu, about, auth, profile labels, aria) | `dict.en` / `dict.es` in `i18n.js` | `BZ.t(key)`, or `data-i18n`, `data-i18n-html`, `data-i18n-aria` |
| Game HUD fallback | `T_UI` in `game.js` | `t(key)` uses `BZ.t` when that returns something other than the key, otherwise `T_UI` |
| Arc cards | `title` / `titleEs`, `body` / `bodyEs`, `label` / `labelEs` on the card | Rendered for the current language |
| Card outcomes | `say(english, spanish)` | Caption follows the language |
| Spoken one-liners | `VOICE_ES` and `CAPTION_RES` in `game.js` | The visible `#caption` is translated. Speech stays English |
| A.I. bud log | `AI_ES` plus `aiVis` | Stored in English (perk rows as `perk:id:tier`) and translated when drawn |
| Perk names | `PERK_NAME` / `PERK_NAME_ES` | Current language |
| Jobs | `job.name` / `job.nameEs`, title ladders | Current language. Payday uses the ladder title for the active language |
| Awards | `AWARD_CATALOG` in `game.js` and `CATALOG` in `u/index.html` | `name` / `nameEs`, `why` / `whyEs`. Keep the two catalogs in step |
| Run chart legend | `t(en, es)` inside `run-stats.js` | Passed both strings at the call |
| Page chrome that is not in the dictionary | small `{ en, es }` or `chanceLang()` branches in `game.js`, `auth.js`, and the HTML pages | Must have both sides |

`about/index.html` is dictionary-only (`data-i18n`). It has no extra copy table.

## How to add a string

1. If the string is shared UI, add the same key to `dict.en` and `dict.es`. Wire it with `data-i18n` or `BZ.t`. A `<label>` that wraps an `<input>` must put `data-i18n` on an inner `<span>`. Setting `textContent` on the label deletes the input.
2. If the game must still show English when `i18n.js` fails to load, add that English line to `T_UI` under the same key. Live copy still comes from the dictionary.
3. For a story card, fill both language fields on the card. Outcome lines go through `say(english, spanish)`. Do not change ids, costs, option keys, or effects.
4. For an award, add `name` / `nameEs` and `why` / `whyEs` in both catalogs. A `secret: true` award stays masked (`???` / the hidden-award label) until that player has it, in both languages. Do not put the secret description in any string that renders before it is earned.
5. A pool line that the HUD speaks should keep its English key and gain a `VOICE_ES` caption. Do not change what `audio.js` speaks.
6. Run `node tools/i18n-audit.js`. It writes `tests/out/i18n-report.md` and exits 1 on any error or unjustified warning. `node --check` the files you edited.
7. Cache tags `?v=mpNNN` in `index.html` must move when these files ship, or players keep the old `i18n.js`. This branch does not pick the next number: `mp193` and `mp194` are already used on other branches. Leave the tags and record the collision in the PR.

`tests/smoke.js` from brief 01 is not on this branch. The audit script is the check. It has no dependencies.

## Editorial rules

- Neutral Spanish. Tú, not vos. Search hits for voseo are audit errors. The scan is documented in the report (Unicode letter boundaries; `poner` + `te` + `los` does not match).
- Same facts in both languages. No new story, no spoilers, no chess solutions, no secret-award descriptions before they are earned.
- TL;DR on a card is the opening sentence of the outcome, plus the next short sentence when the joke needs it, capped near 165 characters. `OUTCOME_TLDR` is the hand-written override. Do not put a different outcome in the summary than in the full line.
- Buttons that name a cost put the amount after a middle dot, with no article in front of the amount (`Comprar el anillo · 8%`).
- Lena does not appear in independence-arc scenes. Marek is dressed for the scene. The A.I. bud never chooses the adopt perk. Do not change that filter while editing copy.
- Do not write the fast-food name or the watch brand named in the repo rules, including in tests and commit messages.

## Hot language switch

Checked in headless Chrome at 390×844 on `http://127.0.0.1:8080/choppy-bitcoin/`.

Updates without reload, on the game document:

- `data-i18n` and `data-i18n-aria` (auth modal included; `auth.js` replays the last message key)
- ready menu, pause menu, perk picker, versus lobby (code field shows `CODE` or `CÓDIGO`)
- HUD labels, including buy / sell and the pause button aria-label (`Pause` / `Pausa`)
- a static arc card title and body (verified on `courage`: Courage ↔ Coraje, body included)
- the next HUD caption (`say`). A buy during a Spanish session showed `¡Rescate de cold storage!`

Stays until the next event or a reload:

- the caption already on screen, until the next `say()`
- an award toast already open (about 3 seconds)
- an auth error string returned by the server
- dynamic card bodies filled at deal time: job, chess (`input === "move"` or id `chess`), `anOffer`, `ambassador`, `firstBloc`, `rearmament`, `threeColors`, `blocReplies`, `blocAssault`, `battleWon`, `blocTriumph`
- any other HTML document. `chart.html` and `profile/index.html` refresh their own title when `setLang` runs on that document. `u/index.html` paints headings, the missing-player lines, and owned awards from the language at load.

Speech is still English. `audio.js` scores Spanish lines down on purpose. Only the visible caption is translated.

## Audit

```
node tools/i18n-audit.js
```

Identical EN/ES strings are errors unless they are in the exception table inside the tool (proper names and the glossary above). The report lists every exception with a reason. Length ratio warns only when the shorter side is at least 28 characters and the ratio is at least 2.8. Unknown `{ident}` tokens are errors. Known tokens (`{n}`, `{i}`, `{have}`, `{offer}`, `{title}`, `{now}`, `{career}`, `{pay}`, `{half}`, `{double}`, `{when}`, `{why}`) are not.

Before this work the first audit snapshot counted 147 errors (dictionary 267/267). Part of that count was the old checker treating input-hint attributes, already-bilingual `say()` calls, and `stampNation` as failures. After the copy fixes and the corrected checker: 0 errors, 0 warnings, dictionary 313/313.
